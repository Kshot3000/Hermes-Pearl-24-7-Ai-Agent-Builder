PRL CLI

Thin, stdlib-only JSON-RPC client for Pearl nodes — one file, no dependencies.

  • python prl status — chain tip, difficulty, sync state
  • python prl block latest — decoded block + tx count
  • python prl check prl1… — offline Taproot address validation
  • Raw passthrough to any RPC method
